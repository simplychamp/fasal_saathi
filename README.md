# FasalSaathi — Beej se Bazaar tak

A polished React/Vite hackathon prototype in Hindi. Features:
- Dashboard with four linked stages
- Rule-based water/fertilizer estimate
- Leaf photo upload UI with clearly labelled simulated diagnosis
- Simulated mandi trend chart and sell-window demo
- Buyer list and stylized map with clearly labelled sample data
- Hindi browser text-to-speech and speech recognition where supported

## Run locally
1. Install Node.js (18+ recommended).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Important demo limitations
This prototype does NOT call a real vision model, live mandi API, weather service, or geolocation/map provider. Disease report, price chart, buyers, distances and prices are simulated. Water/fertilizer figures and profit are illustrative, not agronomic advice. Do not use them for real farm decisions. For pesticide or disease treatment advice, consult your local KVK/agriculture officer.
